# Modules Management System

A Modules Management System built using React and Carbon Design System based on the provided Figma design.

## Features

- View all modules
- Create modules
- Save modules as drafts
- View module details
- Edit modules
- Search modules
- Filter modules
- Review Queue
- Responsive UI

## Tech Stack

- React.js
- Vite
- JavaScript
- Carbon Design System
- CSS

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/saniaakhann/modules-management-system-new.git
2. Navigate to the project
cd modules-management-system-new
3. Install dependencies
npm install
4. Start the development server
npm run dev
