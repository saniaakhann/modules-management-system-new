# Modules Management System

A Modules Management System built using React and Carbon Design System based on the provided Figma design.

## Features

- View all modules
- Create modules
- Save modules as drafts
- View module details
- Edit modules
- Search modules
- Filter modules
- Review Queue
- Responsive UI

## Tech Stack

- React.js
- Vite
- JavaScript
- Carbon Design System
- CSS
